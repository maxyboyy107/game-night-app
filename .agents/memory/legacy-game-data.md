---
name: Legacy game data recovery
description: User guidance for recovering older games.io articles and session history.
---

Prior game articles and session records were reported lost from the databases. The user does not know a recovery source and accepts not restoring them if none is available. Do not recreate old content from guesses; use only an authoritative export, database backup, or source history.

**Why:** The user prefers an honest explanation and durable protection for future records over fabricated history.

**How to apply:** When asked to recover legacy content, check available backups and source history first, explain if no authoritative source exists, and preserve new content with a backup/export path.
